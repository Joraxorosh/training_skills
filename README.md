# Тренажёр скиллов

Веб-тренажёр для подготовки к собеседованиям и проверки знаний. Работает в браузере на телефоне и на компьютере. На телефоне его можно установить на главный экран как приложение (PWA).

**Курсы:** DevOps (120 вопросов, 10 тем) и SQL (120 вопросов, 10 тем).

## Возможности

- Выбор курса, затем режима тренировки:
  - **Вперемешку**: все темы в случайном порядке.
  - **По темам**: одна или несколько выбранных тем.
  - **Работа над ошибками**: вопросы, на которые в последний раз был дан неверный ответ.
  - **Новые вопросы**: только те, что ещё не встречались.
- Настройки теста: число вопросов (10 / 20 / 30 / все), сложность, перемешивание вариантов ответа.
- Два режима проверки: **тренировка** показывает правильный ответ и объяснение сразу, **экзамен** показывает результат только в конце.
- Вопросы с одним и с несколькими правильными ответами, фрагменты кода, конфигов и SQL.
- Результат с разбивкой по темам, разбором каждого вопроса и кнопкой «Повторить ошибки».
- Прогресс и статистика сохраняются в браузере. Незавершённый тест можно продолжить после перезагрузки.
- Светлая и тёмная тема, управление с клавиатуры: `1–9` или `A–J` выбирают вариант, `Enter` отвечает.

## Локальный запуск

Нужен Node.js 18 или новее. Внешних зависимостей нет.

```bash
npm start            # http://localhost:3000
npm run validate     # проверка банков вопросов
```

## Деплой на сервер

### Вариант 1: Docker Compose, доступ по IP

```bash
git clone https://github.com/Joraxorosh/training_skills.git
cd training_skills
docker compose up -d --build
```

Приложение откроется по адресу `http://<IP-сервера>:8080`.

### Вариант 2: HTTPS со своим доменом (рекомендуется для телефона)

HTTPS нужен, чтобы установить приложение на главный экран и чтобы работал офлайн-кэш.

1. Направьте A-запись домена (например, `quiz.example.com`) на IP сервера.
2. Откройте порты 80 и 443.
3. Запустите:

```bash
DOMAIN=quiz.example.com docker compose --profile https up -d --build
```

Caddy сам получит и будет продлевать сертификат Let's Encrypt.

### Вариант 3: без Docker

```bash
PORT=3000 node server.js
```

Сервер лучше держать под systemd или pm2, а перед ним поставить nginx или Caddy для HTTPS.

### Обновление

```bash
git pull && docker compose up -d --build
```

Если HTTPS включён, добавьте в эту команду те же `DOMAIN=...` и `--profile https`, что и при первом запуске.

## Структура проекта

```
public/
  index.html, app.js, styles.css   — SPA без сборки
  sw.js, manifest.webmanifest      — PWA
  data/
    courses.json                   — список курсов
    devops-1.json, devops-2.json   — вопросы DevOps
    sql-1.json, sql-2.json         — вопросы SQL
server.js                          — статический сервер без зависимостей
scripts/validate.js                — проверка формата вопросов
Dockerfile, docker-compose.yml, deploy/Caddyfile
```

## Как добавить курс или вопросы

1. Создайте файл `public/data/<курс>.json`:

```json
{
  "topics": [{ "id": "python-basics", "title": "Основы Python" }],
  "questions": [
    {
      "id": "python-basics-001",
      "topic": "python-basics",
      "difficulty": "easy",
      "type": "single",
      "question": "Что выведет код?",
      "code": "print(2 ** 3)",
      "options": ["6", "8", "9", "23"],
      "correct": [1],
      "explanation": "`**` — возведение в степень, 2³ = 8."
    }
  ]
}
```

   - `difficulty` принимает значения `easy`, `medium` или `hard`.
   - `type` принимает значения `single` или `multiple`.
   - `correct` содержит индексы правильных вариантов, отсчёт с 0.
   - В тексте можно писать `` `inline code` ``.
2. Добавьте курс в `public/data/courses.json`, указав `id`, `title`, `description`, `badge`, `color` и `files`. Один курс может состоять из нескольких файлов.
3. Выполните `npm run validate`.

Глубокое обучение — это нейросети из многих слоёв, которые сами учатся извлекать признаки из сырых данных: пикселей, звука, текста. На собеседовании спрашивают механику обучения (градиенты, оптимизаторы, регуляризация), типичные проблемы (затухание градиентов, забытый `model.eval()`) и устройство трансформера, на котором построены современные LLM.

## Нейрон и функции активации

Нейрон считает взвешенную сумму входов и применяет нелинейность: `y = f(w·x + b)`. Без нелинейности любая глубокая сеть сводится к одной линейной функции.

| Активация | Формула | Где применяют |
|---|---|---|
| ReLU | `max(0, x)` | стандарт для скрытых слоёв |
| GELU / SiLU | гладкие варианты ReLU | трансформеры |
| Sigmoid | `1 / (1 + e^(-x))` | выход бинарной классификации, гейты LSTM |
| Tanh | `tanh(x)`, значения от −1 до 1 | RNN |
| Softmax | `e^(z_i) / Σ e^(z_j)` | выход многоклассовой классификации |

## Функции потерь и оптимизация

- **MSE** — стандарт для регрессии.
- **Cross-entropy** — для классификации: `-log(p_true)`, сильно штрафует уверенную ошибку. В PyTorch `nn.CrossEntropyLoss` принимает логиты и сам применяет softmax.

**Градиентный спуск** двигает веса против градиента: `w = w − lr · grad`. **Backpropagation** эффективно считает градиенты по всем весам через правило цепочки за один обратный проход. На практике используют **мини-батчи** (SGD).

- **SGD с momentum** — накапливает «инерцию» градиента, иногда лучше обобщает.
- **Adam / AdamW** — адаптивный шаг для каждого параметра по скользящим средним градиента и его квадрата; быстрая сходимость по умолчанию. AdamW корректно реализует weight decay.

**Learning rate** — главный гиперпараметр. Слишком большой — loss скачет или уходит в NaN, слишком маленький — обучение ползёт. Используют warmup и расписания (cosine decay).

```python
model.train()
for x, y in loader:
    optimizer.zero_grad()
    loss = loss_fn(model(x), y)
    loss.backward()
    optimizer.step()

model.eval()                 # выключает dropout, BatchNorm берёт running-статистики
with torch.no_grad():        # только отключает построение графа градиентов
    preds = model(x_test)
```

## Проблемы обучения и регуляризация

**Затухание градиентов**: производная сигмоиды не больше 0.25, и при перемножении по десяткам слоёв градиент для первых слоёв исчезает. **Взрыв градиентов** — обратная ситуация. Лечение: ReLU-подобные активации, правильная инициализация (He, Xavier), нормализация, **residual-связи** (`x + f(x)`), gradient clipping.

- **BatchNorm** нормирует активации по батчу, ускоряет и стабилизирует обучение; на инференсе использует накопленные средние. В трансформерах чаще **LayerNorm** — нормировка по признакам одного примера.
- **Dropout** случайно обнуляет активации при обучении и выключается на инференсе.
- Также: weight decay, аугментации данных, early stopping.

## CNN и RNN

**Свёрточные сети** применяют один и тот же небольшой фильтр по всему изображению: локальность и разделение весов дают мало параметров и инвариантность к сдвигу. Параметры `Conv2d(3, 16, kernel_size=3)`: `16 × (3·3·3 + 1) = 448`, не зависят от размера картинки. Pooling уменьшает пространственный размер.

**RNN/LSTM** обрабатывают последовательность шаг за шагом, передавая скрытое состояние. Минусы: обучение не параллелится по времени, дальние зависимости размываются; LSTM с гейтами частично решает затухание, но не последовательность вычислений.

## Attention и трансформер

**Self-attention**: каждый токен через три проекции получает запрос `Q`, ключ `K` и значение `V`. Выход — взвешенная сумма значений: `softmax(QKᵀ / √d_k) · V`.

- Деление на `√d_k` не даёт скалярным произведениям расти с размерностью и насыщать softmax.
- Сложность квадратична по длине последовательности: матрица `n × n`.
- **Multi-head attention** — h голов в подпространствах размерности `d_model / h`; разные головы ловят разные связи, результаты конкатенируются.
- **Positional encoding** нужен, потому что attention не различает порядок токенов: синусоиды, обучаемые позиции или RoPE.

Блок трансформера: attention → residual + LayerNorm → feed-forward (MLP) → residual + LayerNorm.

| Архитектура | Маска | Примеры задач |
|---|---|---|
| Encoder-only (BERT) | двунаправленная | классификация, эмбеддинги, NER |
| Decoder-only (GPT-подобные) | каузальная | генерация текста, современные LLM |
| Encoder-decoder (T5) | энкодер + cross-attention | перевод, суммаризация |

## Transfer learning и GPU

**Transfer learning**: берём модель, предобученную на большом датасете, и дообучаем на своих данных — сначала «голову», потом при необходимости часть слоёв с маленьким lr. При малых данных это почти всегда лучше обучения с нуля.

**GPU** выгодны, потому что нейросеть — это огромные умножения матриц, а GPU выполняет тысячи однотипных операций параллельно и имеет быструю память. Узкие места — объём видеопамяти (веса, активации, состояние оптимизатора) и пропускная способность. Смешанная точность (fp16/bf16) экономит память и ускоряет обучение.

## Частые вопросы на собеседовании

- Зачем нелинейность? → Без неё многослойная сеть эквивалентна одному линейному слою.
- Почему затухают градиенты и как бороться? → Произведение малых производных; ReLU, residual, нормализация, инициализация.
- Что будет, если забыть `model.eval()`? → Dropout останется включён, BatchNorm возьмёт статистики батча.
- Зачем `√d_k` в attention? → Чтобы softmax не насыщался при большой размерности.
- Почему трансформеры вытеснили RNN? → Параллельное обучение и прямая связь любых позиций.
- Encoder vs decoder? → Двунаправленное понимание против каузальной генерации.

## Шпаргалка

- ReLU в скрытых слоях, softmax + cross-entropy на выходе классификатора, MSE для регрессии
- Adam/AdamW по умолчанию; lr — главный гиперпараметр; warmup + decay
- Linear(a, b): `a·b + b` параметров; Conv2d: `out · (k·k·in + 1)`
- dropout, weight decay, аугментации, early stopping
- `model.eval()` + `torch.no_grad()` на инференсе
- attention: `softmax(QKᵀ/√d_k)V`, O(n²), multi-head, позиционное кодирование
- decoder-only — генерация; encoder-only — понимание и эмбеддинги

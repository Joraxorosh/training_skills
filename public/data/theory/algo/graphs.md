Деревья и графы описывают связи: файловую систему, сеть дорог, зависимости пакетов, социальные связи. На собеседовании это самый объёмный раздел: обходы деревьев, BST, BFS и DFS, кратчайшие пути, топологическая сортировка и система непересекающихся множеств. Хорошая новость — большинство задач сводятся к нескольким шаблонам, которые стоит знать наизусть.

## Деревья и обходы

Дерево — связный граф без циклов; у двоичного дерева у каждого узла не больше двух детей. Высота сбалансированного дерева — O(log n), вырожденного (по сути списка) — O(n).

| Обход | Порядок | Применение |
|---|---|---|
| Прямой (pre-order) | узел, левое, правое | копирование, сериализация |
| Центрированный (in-order) | левое, узел, правое | BST → отсортированная последовательность |
| Обратный (post-order) | левое, правое, узел | удаление, вычисление высоты |
| В ширину (level-order) | по уровням | минимальная глубина, вид сбоку |

```python
from collections import deque

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val, self.left, self.right = val, left, right

def inorder(node):
    return inorder(node.left) + [node.val] + inorder(node.right) if node else []

def height(node):
    return 1 + max(height(node.left), height(node.right)) if node else 0

def levels(root):
    res, q = [], deque([root])
    while q:
        res.append([n.val for n in q])
        q = deque(c for n in q for c in (n.left, n.right) if c)
    return res

#       4
#     2   6
#    1 3   7
root = TreeNode(4, TreeNode(2, TreeNode(1), TreeNode(3)), TreeNode(6, None, TreeNode(7)))
print(inorder(root), height(root))   # [1, 2, 3, 4, 6, 7] 3
print(levels(root))                  # [[4], [2, 6], [1, 3, 7]]
```

## BST и балансировка

**Двоичное дерево поиска**: все ключи в левом поддереве меньше узла, в правом — больше. Поиск, вставка, удаление — O(h): O(log n) у сбалансированного и O(n) у вырожденного (вставка отсортированных данных). Поэтому на практике используют самобалансирующиеся деревья: **AVL** (строгий баланс, высоты поддеревьев отличаются не более чем на 1) и **красно-чёрное** (менее строгое, меньше поворотов при вставке; используется в `TreeMap` Java и `std::map` C++). Баланс восстанавливается поворотами.

> Частая ошибка в задаче «проверить, что дерево — BST»: сравнивать узел только с детьми. Нужно передавать допустимый диапазон `(low, high)` вниз по рекурсии или проверить, что in-order обход строго возрастает.

## Префиксное дерево (trie)

Trie хранит строки посимвольно: путь от корня — префикс. Вставка и поиск — O(длина слова), независимо от числа слов. Применение: автодополнение, проверка префиксов, поиск слов в сетке.

```python
class Trie:
    def __init__(self):
        self.root = {}
    def insert(self, word):
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})
        node["$"] = True
    def starts_with(self, prefix):
        node = self.root
        for ch in prefix:
            if ch not in node:
                return False
            node = node[ch]
        return True

t = Trie()
for w in ["cat", "car", "dog"]:
    t.insert(w)
print(t.starts_with("ca"), t.starts_with("co"))   # True False
```

## Представление графов, BFS и DFS

| Представление | Память | Проверка ребра | Обход соседей | Когда |
|---|---|---|---|---|
| Список смежности | O(V + E) | O(deg) | O(deg) | разреженные графы — почти всегда |
| Матрица смежности | O(V²) | O(1) | O(V) | плотные графы, Флойд–Уоршелл |
| Список рёбер | O(E) | O(E) | O(E) | Краскал, Беллман–Форд |

**BFS** (в ширину) использует очередь и находит **кратчайший путь в невзвешенном графе**. **DFS** (в глубину) использует стек или рекурсию: компоненты связности, поиск циклов, топологическая сортировка, перебор путей. Оба — O(V + E). Не забывайте множество `visited`, иначе зациклитесь.

```python
graph = {"A": ["B", "C"], "B": ["D"], "C": ["D", "E"], "D": ["F"], "E": ["F"], "F": []}

def bfs_dist(g, start):
    dist, q = {start: 0}, deque([start])
    while q:
        u = q.popleft()
        for v in g[u]:
            if v not in dist:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

def dfs(g, u, seen=None):
    if seen is None:
        seen = {}                     # dict сохраняет порядок посещения
    seen[u] = True
    for v in g[u]:
        if v not in seen:
            dfs(g, v, seen)
    return list(seen)

print(bfs_dist(graph, "A"))   # {'A': 0, 'B': 1, 'C': 1, 'D': 2, 'E': 2, 'F': 3}
print(dfs(graph, "A"))        # ['A', 'B', 'D', 'F', 'C', 'E']
```

## Кратчайшие пути

| Алгоритм | Веса | Сложность | Особенности |
|---|---|---|---|
| BFS | невзвешенный | O(V + E) | самый простой |
| 0-1 BFS | 0 и 1 | O(V + E) | дек: вес 0 — в начало |
| Дейкстра | неотрицательные | O((V + E) log V) | жадный, с кучей |
| Беллман–Форд | любые | O(V * E) | находит отрицательные циклы |
| Флойд–Уоршелл | любые, все пары | O(V³) | матрица, малые V |

```python
import heapq

def dijkstra(g, src):
    dist = {src: 0}
    pq = [(0, src)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]:
            continue                  # устаревшая запись в куче
        for v, w in g[u]:
            nd = d + w
            if nd < dist.get(v, float("inf")):
                dist[v] = nd
                heapq.heappush(pq, (nd, v))
    return dist

wg = {"A": [("B", 4), ("C", 1)], "C": [("B", 2), ("D", 7)], "B": [("D", 1)], "D": []}
print(dijkstra(wg, "A"))      # {'A': 0, 'B': 3, 'C': 1, 'D': 4}
```

> Дейкстра неверно работает с отрицательными весами: вершина, извлечённая из кучи, считается окончательной, а отрицательное ребро могло бы улучшить путь позже. Для таких графов — Беллман–Форд (V-1 раундов релаксации всех рёбер; если на V-м раунде что-то улучшилось — есть отрицательный цикл).

## Топологическая сортировка, union-find и MST

**Топологическая сортировка** — порядок вершин ориентированного ациклического графа (DAG), в котором каждое ребро идёт вперёд: порядок сборки, расписание курсов. Алгоритм Кана: берём вершины с нулевой входящей степенью, удаляем их рёбра. Если обработали не все вершины — в графе цикл.

```python
def topo_sort(g):
    indeg = {u: 0 for u in g}
    for u in g:
        for v in g[u]:
            indeg[v] += 1
    q = deque(u for u in g if indeg[u] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in g[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == len(g) else None   # None — есть цикл

print(topo_sort(graph))       # ['A', 'B', 'C', 'D', 'E', 'F']
```

**Union-Find (DSU)** поддерживает разбиение на непересекающиеся множества: `find` — представитель множества, `union` — объединение. Со сжатием путей и объединением по рангу операции почти O(1) (обратная функция Аккермана). Применения: компоненты связности, поиск цикла в неориентированном графе, алгоритм Краскала.

```python
class DSU:
    def __init__(self, n):
        self.parent, self.rank = list(range(n)), [0] * n
    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])   # сжатие путей
        return self.parent[x]
    def union(self, a, b):
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False
        if self.rank[ra] < self.rank[rb]:
            ra, rb = rb, ra
        self.parent[rb] = ra
        self.rank[ra] += self.rank[ra] == self.rank[rb]
        return True

def kruskal(n, edges):                   # edges: (w, u, v)
    dsu, total = DSU(n), 0
    for w, u, v in sorted(edges):
        if dsu.union(u, v):
            total += w
    return total

print(kruskal(4, [(1, 0, 1), (4, 0, 2), (3, 1, 2), (2, 2, 3), (5, 1, 3)]))   # 6
```

**Минимальное остовное дерево** (MST) связывает все вершины рёбрами минимального суммарного веса. **Краскал**: сортируем рёбра и добавляем, если они не образуют цикл (проверка через DSU) — O(E log E). **Прим**: растим дерево из вершины, каждый раз добавляя самое дешёвое ребро наружу через кучу — O(E log V).

## Частые вопросы на собеседовании

- Как найти кратчайший путь в невзвешенном графе? → BFS.
- Почему Дейкстра не работает с отрицательными весами? → извлечённая вершина считается окончательной; нужен Беллман–Форд.
- Как проверить, что дерево — BST? → рекурсия с границами `(low, high)` или возрастающий in-order.
- Как обнаружить цикл в ориентированном графе? → DFS с тремя цветами или Кан: не все вершины попали в порядок.
- Что дают сжатие путей и ранги в DSU? → почти O(1) на операцию.
- Список смежности или матрица? → список для разреженных графов, матрица для плотных и O(1) проверки ребра.

## Шпаргалка

- In-order обход BST даёт отсортированный порядок.
- Операции BST — O(h); баланс (AVL, красно-чёрное) гарантирует O(log n).
- Trie: операции O(длина слова).
- BFS — очередь, кратчайший путь без весов; DFS — стек/рекурсия; оба O(V + E).
- Дейкстра — куча, веса не отрицательные; Беллман–Форд — отрицательные веса и циклы.
- Топосорт — алгоритм Кана, только для DAG.
- DSU: `find` со сжатием путей + `union` по рангу; Краскал = сортировка рёбер + DSU.

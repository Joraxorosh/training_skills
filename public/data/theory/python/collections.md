Встроенные коллекции — основной рабочий инструмент Python-разработчика. На собеседовании проверяют, понимаете ли вы, как они устроены внутри: какая операция сколько стоит, почему ключом словаря не может быть список и чем поверхностная копия отличается от глубокой. Плюс идиомы: comprehensions, модуль `collections`, сортировка по ключу и распаковка.

## Четыре базовые коллекции

| Тип | Упорядочен | Изменяем | Дубликаты | Литерал |
|---|---|---|---|---|
| `list` | да | да | да | `[1, 2]` |
| `tuple` | да | нет | да | `(1, 2)` или `1, 2` |
| `dict` | да (порядок вставки, 3.7+) | да | ключи уникальны | `{"a": 1}` |
| `set` | нет | да | нет | `{1, 2}` |

`{}` — это пустой **словарь**; пустое множество создаётся только через `set()`. Кортеж из одного элемента пишется с запятой: `(1,)`.

## Сложность операций

`list` — динамический массив указателей. `dict` и `set` — хеш-таблицы.

| Операция | list | dict / set |
|---|---|---|
| Доступ по индексу / ключу | O(1) | O(1) в среднем |
| `append` / добавление | O(1) амортизированно | O(1) в среднем |
| `pop()` с конца | O(1) | — |
| `insert(0, x)`, `pop(0)` | O(n) | — |
| `x in coll` | O(n) | O(1) в среднем |
| Удаление по значению | O(n) | O(1) в среднем |
| Сортировка | O(n log n) | — |

Если нужна очередь с быстрым удалением слева — `collections.deque` (O(1) с обоих концов). Если много проверок `in` — переведите список в `set`.

## Хешируемость

Ключом `dict` и элементом `set` может быть только **хешируемый** объект: у него есть `__hash__`, хеш не меняется за время жизни, а равные объекты имеют равные хеши. Неизменяемые встроенные типы хешируемы; `list`, `dict`, `set` — нет. Кортеж хешируем, только если хешируемы все его элементы.

```python
d = {(1, 2): "ok", frozenset({3}): "ok"}
try:
    d[[1, 2]] = "bad"
except TypeError as e:
    print(e)               # unhashable type: 'list'

print(hash(1) == hash(1.0) == hash(True))   # True
print({1: "a", 1.0: "b", True: "c"})        # {1: 'c'}
```

## Копирование и ловушка [[]] * 3

Присваивание не копирует. `list.copy()`, `lst[:]`, `list(lst)`, `copy.copy` создают **поверхностную** копию: новый внешний контейнер, но те же вложенные объекты. `copy.deepcopy` рекурсивно копирует всё.

```python
import copy
orig = [[1, 2], [3]]
shallow = copy.copy(orig)
deep = copy.deepcopy(orig)
orig[0].append(99)
print(shallow)             # [[1, 2, 99], [3]]
print(deep)                # [[1, 2], [3]]

grid = [[]] * 3            # три ссылки на ОДИН список
grid[0].append("x")
print(grid)                # [['x'], ['x'], ['x']]

grid = [[] for _ in range(3)]   # правильно: три разных списка
grid[0].append("x")
print(grid)                # [['x'], [], []]
```

> Классическая задача: «создайте матрицу 3x3 из нулей». Ответ `[[0] * 3] * 3` — ошибка, все строки будут одним объектом. Правильно: `[[0] * 3 for _ in range(3)]`.

## Comprehensions

Списковые, словарные и множественные включения короче и обычно быстрее цикла с `append`. Переменная цикла не «протекает» наружу (Python 3).

```python
nums = range(10)
squares = [x * x for x in nums if x % 2 == 0]
print(squares)                         # [0, 4, 16, 36, 64]
print({x: x % 3 for x in range(5)})    # {0: 0, 1: 1, 2: 2, 3: 0, 4: 1}
print({len(w) for w in ["a", "bb", "cc"]})   # {1, 2}
pairs = [(i, j) for i in range(2) for j in "ab"]
print(pairs)               # [(0, 'a'), (0, 'b'), (1, 'a'), (1, 'b')]
print(["even" if x % 2 == 0 else "odd" for x in range(3)])   # ['even', 'odd', 'even']
```

Круглые скобки дают не «tuple comprehension», а **генераторное выражение** — ленивый итератор.

## Модуль collections

- `Counter` — подсчёт элементов, `most_common(k)`.
- `defaultdict(factory)` — создаёт значение по умолчанию при обращении к отсутствующему ключу.
- `deque` — двусторонняя очередь, `maxlen` для кольцевого буфера.
- `namedtuple` — кортеж с именованными полями.
- `OrderedDict` — `move_to_end`, `popitem(last=False)`; полезен для LRU.
- `ChainMap` — поиск по цепочке словарей.

```python
from collections import Counter, defaultdict, deque, namedtuple
print(Counter("abracadabra").most_common(2))   # [('a', 5), ('b', 2)]

groups = defaultdict(list)
for w in ["apple", "avocado", "banana"]:
    groups[w[0]].append(w)
print(dict(groups))        # {'a': ['apple', 'avocado'], 'b': ['banana']}

q = deque([1, 2, 3], maxlen=3)
q.append(4)
print(q)                   # deque([2, 3, 4], maxlen=3)

Point = namedtuple("Point", "x y")
print(Point(1, 2).x)       # 1
```

## Сортировка и распаковка

`sorted(it)` возвращает новый список, `list.sort()` сортирует на месте и возвращает `None`. Обе стабильны (Timsort) и принимают `key` и `reverse`.

```python
people = [("Bob", 25), ("Ann", 30), ("Cid", 25)]
print(sorted(people, key=lambda p: (-p[1], p[0])))
# [('Ann', 30), ('Bob', 25), ('Cid', 25)]
print(sorted(["b", "A", "c"], key=str.lower))  # ['A', 'b', 'c']

first, *rest = [1, 2, 3, 4]
print(first, rest)         # 1 [2, 3, 4]
a, b = 1, 2
a, b = b, a
print(a, b)                # 2 1
merged = {**{"x": 1}, **{"x": 2, "y": 3}}
print(merged)              # {'x': 2, 'y': 3}
print({"x": 1} | {"y": 2}) # {'x': 1, 'y': 2}
```

## Частые вопросы на собеседовании

- Почему `list` нельзя сделать ключом словаря? → он изменяем и не хешируется; используйте `tuple`.
- Сложность `x in list` и `x in set`? → O(n) и O(1) в среднем.
- Чем `copy` отличается от `deepcopy`? → поверхностная копия разделяет вложенные объекты, глубокая — нет.
- Что выведет `[[]] * 3` после `append` в первый элемент? → изменятся все три, это один объект.
- Разница `sorted` и `.sort()`? → новый список против сортировки на месте с возвратом `None`.
- Сохраняет ли `dict` порядок? → да, порядок вставки гарантирован с Python 3.7.

## Шпаргалка

- `{}` — dict, `set()` — пустое множество, `(1,)` — кортеж из одного.
- list: индекс O(1), `in` O(n), вставка в начало O(n). dict/set: всё O(1) в среднем.
- Ключ должен быть хешируемым; `1`, `1.0`, `True` — один ключ.
- Вложенные структуры копировать через `deepcopy`.
- Матрица: `[[0] * m for _ in range(n)]`.
- `Counter`, `defaultdict`, `deque` закрывают половину задач.
- Сортировка стабильна; сложный порядок — кортеж в `key`.

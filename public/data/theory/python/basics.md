Python — язык с динамической, но строгой типизацией: у переменной нет типа, тип есть у объекта, на который она ссылается. Большинство вопросов на собеседовании по основам крутятся вокруг трёх идей: всё — объект, имя — это ссылка, а объекты бывают изменяемыми и неизменяемыми. Разберём встроенные типы, операторы и их неочевидное поведение.

## Числа: int и float

`int` в Python имеет **произвольную точность** — переполнения нет, число растёт, пока хватает памяти. `float` — это 64-битное число IEEE 754, поэтому десятичные дроби хранятся приближённо.

```python
print(2 ** 100)            # 1267650600228229401496703205376
print(0.1 + 0.2)           # 0.30000000000000004
print(0.1 + 0.2 == 0.3)    # False

import math
from decimal import Decimal
print(math.isclose(0.1 + 0.2, 0.3))          # True
print(Decimal("0.1") + Decimal("0.2"))       # 0.3
print(round(2.5), round(3.5))                # 2 4  (банковское округление)
```

Для денег используют `Decimal` или хранят суммы в копейках как `int`. Деление `/` всегда возвращает `float`, даже `4 / 2 == 2.0`.

### Целочисленное деление и остаток

`//` округляет **вниз** (к минус бесконечности), а не к нулю, как в C или Java. Знак `%` совпадает со знаком делителя. Всегда выполняется `a == (a // b) * b + a % b`.

```python
print(7 // 2, -7 // 2)     # 3 -4
print(7 % 3, -7 % 3)       # 1 2
print(7 % -3)              # -2
print(int(-7 / 2))         # -3  (усечение к нулю)
print(divmod(-7, 2))       # (-4, 1)
```

## is против ==

`==` сравнивает **значения** (вызывает `__eq__`), `is` — **идентичность**, то есть один ли это объект в памяти (`id(a) == id(b)`). `is` используют только для синглтонов: `None`, `True`, `False`, `...`.

```python
a = [1, 2]
b = [1, 2]
print(a == b, a is b)      # True False

x = 256; y = 256
print(x is y)              # True — CPython кэширует int от -5 до 256
print(x is None)           # False — правильная проверка на None
```

> На собеседовании любят спрашивать, почему `a is b` для маленьких чисел даёт `True`, а для больших может дать `False`. Ответ: кэш малых int и интернирование строк — деталь реализации CPython, на неё нельзя полагаться. Сравнивайте значения через `==`.

## Изменяемость

| Неизменяемые | Изменяемые |
|---|---|
| `int`, `float`, `bool`, `str` | `list` |
| `tuple`, `frozenset`, `bytes` | `dict`, `set`, `bytearray` |
| `None` | пользовательские объекты (по умолчанию) |

Присваивание не копирует объект, а создаёт ещё одну ссылку. Изменение через одно имя видно через другое. Для неизменяемых типов «изменение» на самом деле создаёт новый объект.

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)                   # [1, 2, 3, 4]

s = "hi"
t = s
t += "!"
print(s, t)                # hi hi!

t2 = ([1], 2)
t2[0].append(9)
print(t2)                  # ([1, 9], 2) — кортеж неизменяем, но его элемент — нет
```

Аргументы в функции передаются «по ссылке на объект» (call by sharing): функция может изменить переданный список, но не может перепривязать имя у вызывающего.

## Истинность (truthiness)

В логическом контексте ложны: `None`, `False`, `0`, `0.0`, `0j`, пустые `""`, `[]`, `()`, `{}`, `set()`, `range(0)`. Всё остальное истинно. Пользовательский класс может определить `__bool__` или `__len__`.

```python
print(bool([]), bool([0]), bool("0"), bool(0.0))   # False True True False
```

> Ловушка: `if x:` и `if x is not None:` — не одно и то же. Если `x` может быть `0` или пустой строкой, нужна явная проверка на `None`.

## Логические операторы и short-circuit

`and` и `or` возвращают **один из операндов**, а не обязательно `bool`, и вычисляют правый операнд только при необходимости. `not` всегда возвращает `bool`.

```python
print(0 or "default")      # default
print("a" and "b")         # b
print([] and 1/0)          # []  — деление не выполнялось
print(1 < 2 < 3)           # True — цепочка сравнений: 1 < 2 and 2 < 3
```

## f-строки, walrus и match

f-строки поддерживают форматирование и отладочный вывод `=`. Оператор морж `:=` (3.8+) присваивает значение внутри выражения. `match` (3.10+) — структурное сопоставление с образцом, а не просто switch.

```python
name, pi = "Ann", 3.14159
print(f"{name!r:>6} {pi:.2f} {pi=}")   #  'Ann' 3.14 pi=3.14159
print(f"{1_000_000:,}")                # 1,000,000

data = [1, 2, 3, 4, 5]
if (n := len(data)) > 3:
    print(f"long: {n}")                # long: 5

def describe(cmd):
    match cmd:
        case ["go", direction]:
            return f"move {direction}"
        case {"x": x, "y": y}:
            return f"point {x},{y}"
        case int() | float() as num if num > 0:
            return "positive"
        case _:
            return "unknown"

print(describe(["go", "north"]))       # move north
print(describe({"x": 1, "y": 2}))      # point 1,2
print(describe(5))                     # positive
```

> В `case` голое имя всегда **захватывает** значение, а не сравнивает с переменной. `case RED:` поймает всё подряд; для констант используйте точечное имя `case Color.RED:`.

## Частые вопросы на собеседовании

- Чем `is` отличается от `==`? → `is` проверяет, один ли это объект, `==` — равенство значений.
- Почему `0.1 + 0.2 != 0.3`? → двоичное представление float неточно; используйте `math.isclose` или `Decimal`.
- Чему равно `-7 // 2`? → `-4`, деление округляет вниз; `-7 % 2 == 1`.
- Как передаются аргументы в функцию? → по ссылке на объект; изменяемый объект можно мутировать внутри функции.
- Что вернёт `0 or [] or "x"`? → `"x"`, первый истинный операнд (или последний, если все ложны).
- Можно ли изменить кортеж? → сам кортеж нет, но изменяемый объект внутри него — да; такой кортеж не хешируется.

## Шпаргалка

- `int` без переполнения; `float` приближённый; деньги — `Decimal`.
- `//` округляет вниз, `%` имеет знак делителя.
- `is` — только для `None`/`True`/`False`; для значений — `==`.
- Присваивание = новая ссылка, не копия.
- Ложны: `None`, `0`, пустые коллекции и строки.
- `and`/`or` возвращают операнд и ленивы.
- `round` использует банковское округление: `round(2.5) == 2`.
- `f"{x=}"` для отладки, `:=` для присваивания в выражении, `match` для разбора структур.

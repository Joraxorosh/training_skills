Статистика — фундамент работы аналитика: она отвечает на вопрос, что в данных является сигналом, а что случайным шумом. На собеседованиях проверяют не умение выводить формулы, а понимание: какую меру центра выбрать, что такое стандартная ошибка, как читать доверительный интервал и почему корреляция не доказывает причинность.

## Меры центра и разброса

- **Среднее** — сумма, делённая на число наблюдений. Чувствительно к выбросам.
- **Медиана** — значение посередине отсортированной выборки. Устойчива к выбросам.
- **Мода** — самое частое значение, полезна для категорий.
- **Дисперсия** — средний квадрат отклонения от среднего; **стандартное отклонение** `σ` — корень из неё, в единицах исходных данных.
- **Перцентиль** p — значение, ниже которого лежит p% наблюдений. p50 — медиана, p25 и p75 — квартили, `IQR = p75 − p25`.

```python
import numpy as np
import pandas as pd

x = np.array([1, 2, 3, 4, 100])
np.mean(x), np.median(x)      # 22.0, 3.0 — один выброс
np.std(x)                     # ddof=0: делим на n
pd.Series(x).std()            # ddof=1: делим на n − 1
```

Выборочную дисперсию делят на `n − 1` (поправка Бесселя), чтобы оценка не была смещённой. NumPy по умолчанию использует `ddof=0`, pandas — `ddof=1`, отсюда расхождения в цифрах.

Для задержек сервисов и чеков почти всегда смотрят медиану и p95/p99: среднее при длинном хвосте описывает «никого».

## Распределения

| Распределение | Что описывает | Пример |
|---|---|---|
| Нормальное | Сумма многих малых независимых эффектов | Рост, ошибки измерения, средние по выборкам |
| Биномиальное | Число успехов в n испытаниях с вероятностью p | Покупки среди 1000 посетителей |
| Пуассона | Число событий за интервал при постоянной интенсивности | Обращения в поддержку за час |
| Логнормальное | Величина, логарифм которой нормален | Чеки, время сессии, доход |
| Парето и другие тяжёлые хвосты | Редкие огромные значения | Выручка от «китов», размеры файлов |

Правило 68–95–99.7 для нормального: в пределах ±1σ лежит около 68% значений, ±2σ — около 95%, ±3σ — 99.7%. У биномиального среднее `n·p`, дисперсия `n·p·(1−p)`. У Пуассона среднее равно дисперсии `λ`.

У логнормального и других скошенных распределений среднее больше медианы. В метриках денег это норма: несколько крупных покупателей двигают ARPU сильнее тысяч обычных. Помогают логарифмирование, винзоризация (обрезка по p99) и устойчивые статистики.

## ЦПТ, стандартная ошибка и доверительные интервалы

**Центральная предельная теорема**: распределение выборочного среднего независимых наблюдений с конечной дисперсией при росте n приближается к нормальному — какой бы формы ни были сами данные. Данные при этом не становятся нормальными.

Разброс выборочного среднего описывает **стандартная ошибка**: `SE = σ / √n`. Отсюда 95% доверительный интервал для среднего: `mean ± 1.96 · SE`.

```python
sd, n, mean = 20, 400, 50
se = sd / np.sqrt(n)                       # 1.0
mean - 1.96 * se, mean + 1.96 * se         # (48.04, 51.96)
```

Ширина интервала падает как `√n`: чтобы сузить его вдвое, нужна вчетверо большая выборка.

> 95% — свойство процедуры, а не конкретного интервала: если много раз повторить выборку, около 95% построенных интервалов накроют истинное среднее. Фраза «параметр с вероятностью 95% лежит в [48, 52]» — байесовская трактовка.

ЦПТ ломается при бесконечной дисперсии (Коши, Парето с малым α): среднее выборки нестабильно, и «n > 30» не спасает.

## Корреляция и причинность

**Пирсон** измеряет силу линейной связи, лежит в [−1, 1] и чувствителен к выбросам. **Спирмен** — корреляция Пирсона по рангам: ловит любую монотонную связь и устойчивее к выбросам.

```python
x = pd.Series(range(1, 11))
y = x ** 3
x.corr(y)                        # ≈ 0.928 — связь нелинейна
x.corr(y, method='spearman')     # 1.0 — связь строго монотонна
```

`r = 0` не означает независимость: у `y = x²` на симметричном интервале r ≈ 0.

Корреляция не доказывает причинность. Причины ложных связей: **конфаундер** (жара влияет и на мороженое, и на утопления), обратная причинность, совпадение трендов во времени. Причинность устанавливают экспериментом или методами causal inference.

## Ловушки интерпретации

**Парадокс Симпсона** — тренд внутри каждого сегмента меняет знак при объединении. Причина — разный состав групп. Пример: лечение A лучше B и для малых, и для крупных камней, но в сумме хуже, потому что A чаще давали тяжёлым пациентам. Лекарство — анализ по сегментам и взвешивание.

**Ошибка выжившего** — выводы только по «дожившим» объектам. Изучая лишь лояльных клиентов, нельзя понять, что их отличает: те же признаки могли быть у ушедших.

**Регрессия к среднему** — после экстремального значения следующее обычно ближе к норме. Худшие магазины «улучшатся» и без вмешательства, поэтому нужен контроль.

## Частые вопросы на собеседовании

- Когда медиана лучше среднего? → При скошенных распределениях и выбросах: зарплаты, чеки, задержки.
- Что такое стандартная ошибка? → Стандартное отклонение выборочной оценки: `σ / √n`.
- Что говорит ЦПТ? → Среднее выборки примерно нормально при большом n и конечной дисперсии; сами данные — нет.
- Как трактовать 95% доверительный интервал? → 95% таких интервалов при повторениях накрывают истинный параметр.
- Пирсон или Спирмен? → Пирсон — линейная связь; Спирмен — монотонная, устойчив к выбросам.
- Что такое парадокс Симпсона? → Смена направления эффекта при агрегации из-за разных весов сегментов.

Визуализация — способ быстро передать вывод из данных людям, которые не будут читать таблицы. Хороший график отвечает на один вопрос, плохой — запутывает или прямо вводит в заблуждение. На собеседовании спрашивают, какой график выбрать для задачи, какие приёмы искажают восприятие, как проектировать дашборд и чем различаются BI-инструменты.

## Выбор типа графика

Начинайте с вопроса: что нужно показать — динамику, сравнение, распределение, связь или состав?

| Задача | График | Комментарий |
|---|---|---|
| Динамика во времени | Линейный | Тренд и сезонность; ось X упорядочена |
| Сравнение категорий | Столбчатый (bar) | Сортировка по значению, горизонтальный при длинных подписях |
| Распределение одной величины | Гистограмма | Подбирайте ширину бинов |
| Сравнение распределений групп | Box plot, violin, ECDF | Медиана, квартили, выбросы |
| Связь двух числовых | Scatter | Прозрачность или hexbin при множестве точек |
| Матрица значений | Heatmap | Корреляции, когорты, день недели × час |
| Доли целого | Stacked bar, иногда pie | Pie — только для 2–3 долей |

Линию проводят только между упорядоченными точками: время, возраст, шаг воронки. Для городов или каналов — столбцы.

**Box plot**: ящик от Q1 до Q3 (IQR), линия — медиана, усы обычно до 1.5·IQR, точки за ними — выбросы. Для распределений с длинным хвостом (время загрузки, чеки) используйте логарифмическую шкалу.

## Как графики вводят в заблуждение

- **Обрезанная ось у столбцов.** Длина столбца кодирует значение; ось от 95 превращает разницу 96 vs 98 в «втрое больше». Для линейных графиков ненулевая ось допустима.
- **Две оси Y.** Масштабы произвольны: подбирая их, можно «совместить» любые ряды. Честнее — два графика с общей осью X или индексирование к 100.
- **Круговые диаграммы.** Углы и площади сравниваются плохо; 3D-эффект ещё и искажает ближние секторы.
- **Неравные интервалы времени** и выборочные периоды, подобранные под нужный вывод.
- **Средние без разброса.** Добавляйте доверительные интервалы или показывайте распределение.
- **Палитра.** Sequential — для величины от малого к большому, diverging — для отклонений от нуля или цели, categorical — для категорий. Радужная палитра создаёт ложные границы.

> Шумный дневной ряд сглаживают скользящим средним за 7 дней (оно же убирает эффект дня недели) или агрегируют по неделям, а неопределённость показывают полосой.

## matplotlib и seaborn

```python
import matplotlib.pyplot as plt
import seaborn as sns

fig, axes = plt.subplots(1, 2, figsize=(12, 4))   # axes.shape == (2,)
daily.plot(ax=axes[0], title='DAU')
axes[0].set_ylim(bottom=0)

sns.boxplot(data=df, x='group', y='revenue', ax=axes[1])
axes[1].set_yscale('log')
fig.tight_layout()
fig.savefig('report.png', dpi=150)
```

- matplotlib — низкоуровневая основа: `Figure` содержит `Axes`, у каждой оси свои методы `plot`, `bar`, `hist`, `scatter`.
- `plt.subplots(nrows, ncols)` возвращает массив осей формы (nrows, ncols).
- seaborn работает с DataFrame и именами столбцов: `histplot`, `boxplot`, `violinplot`, `scatterplot`, `lineplot`, `barplot`, `heatmap`, параметр `hue` для разбиения по цвету.
- Для корреляций: `sns.heatmap(df.corr(), cmap='RdBu', vmin=-1, vmax=1, center=0, annot=True)`.

## Сторителлинг с данными

- Заголовок графика формулирует вывод: «Конверсия упала на 12% после релиза 3.4», а не «Конверсия по дням».
- Структура: контекст → инсайт → рекомендация, что делать.
- Убирайте лишнее (рамки, сетку, легенды, которые можно заменить подписями), выделяйте главное акцентным цветом.
- Один график — одна мысль; сложный вывод разбивайте на последовательность.

## Частые вопросы на собеседовании

- Какой график для динамики, распределения, связи? → Линия, гистограмма или box plot, scatter.
- Почему не стоит использовать pie chart? → Углы сравниваются плохо; столбцы точнее.
- Когда ось Y обязана начинаться с нуля? → У столбчатых диаграмм, где значение — длина.
- Чем плоха двойная ось? → Произвольные масштабы создают ложные связи.
- Как устроить дашборд? → KPI сверху, объяснения ниже, детализация внизу, под конкретную аудиторию.
- Какую палитру для корреляций? → Diverging с нулём в центре.

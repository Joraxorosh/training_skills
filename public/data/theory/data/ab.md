A/B-тест — рандомизированный эксперимент: пользователей случайно делят на контроль (A) и тест (B), а потом проверяют, отличается ли метрика сильнее, чем можно объяснить случайностью. Это основной способ доказать причинный эффект изменения в продукте. На собеседовании ждут понимания p-value, мощности, расчёта выборки и типичных ловушек: подглядывания, множественных сравнений, SRM.

## Гипотезы, p-value и ошибки

- **H0** — эффекта нет (разница метрик равна нулю). **H1** — эффект есть.
- **p-value** — вероятность получить такой же или более экстремальный результат, если H0 верна.
- **α** (обычно 0.05) — допустимая вероятность ошибки I рода: найти эффект, которого нет.
- **β** — вероятность ошибки II рода: пропустить реальный эффект. **Мощность** = `1 − β`, обычно 80%.

| | H0 верна | H1 верна |
|---|---|---|
| Отвергли H0 | Ошибка I рода (α) | Верное открытие (мощность) |
| Не отвергли H0 | Верно | Ошибка II рода (β) |

> p-value не равно вероятности того, что H0 верна, и не говорит, что «B лучше с вероятностью 97%». Оно ничего не говорит и о размере эффекта: при огромной выборке даже ничтожная разница значима. Размер эффекта показывает доверительный интервал разницы.

## MDE и размер выборки

**MDE** — минимальный эффект, который тест надёжно обнаружит при заданных α, мощности и выборке. Его выбирают из бизнес-смысла и по нему считают выборку.

```python
from scipy.stats import norm

p, mde = 0.10, 0.01                        # конверсия 10%, ищем +1 п.п.
z = norm.ppf(0.975) + norm.ppf(0.80)       # 1.96 + 0.84
n = z ** 2 * 2 * p * (1 - p) / mde ** 2    # ≈ 14 128 на группу
```

Общая формула: `n ∝ (z₁₋α/₂ + z₁₋β)² · σ² / MDE²`. Отсюда: уменьшить MDE вдвое — выборка ×4; снизить дисперсию метрики — выборка меньше. Длительность теста выбирают целым числом недель, чтобы учесть недельную сезонность.

## Какой тест выбрать

| Ситуация | Тест |
|---|---|
| Доля (конверсия), большая выборка | z-тест для пропорций или хи-квадрат 2×2 |
| Среднее (чек, время), большая выборка | t-тест Уэлча |
| Распределение по категориям | Хи-квадрат по таблице сопряжённости |
| Порядковые данные, малые выборки, выбросы | Mann-Whitney |
| Медиана, квантиль, сложная метрика | Бутстрап |
| Ratio-метрика (CTR, средний чек по заказам) | Дельта-метод, линеаризация, бутстрап по пользователям |

z-тест предполагает известную дисперсию, t-тест оценивает её по выборке; при тысячах наблюдений они практически совпадают. Mann-Whitney проверяет сдвиг распределений (стохастическое доминирование), а не равенство средних — это важно при интерпретации.

**Ratio-метрики.** Если рандомизируем пользователей, а CTR считаем как клики / показы, наблюдения внутри пользователя зависимы. Наивный t-тест по показам занижает дисперсию и даёт ложные прокрасы. Дисперсию отношения считают дельта-методом или бутстрапом с ресемплингом пользователей.

**Бутстрап**: тысячи раз ресемплируем выборку с возвращением, считаем статистику, берём 2.5-й и 97.5-й перцентили — получаем доверительный интервал без формул.

## Ловушки

**Подглядывание (peeking).** Если смотреть p-value каждый день и остановиться при первом p < 0.05, ошибка I рода вырастает в разы. Решения: фиксированный горизонт или последовательное тестирование (alpha spending, mSPRT).

**Множественные сравнения.** При 10 независимых метриках шанс хотя бы одного ложного прокраса — `1 − 0.95¹⁰ ≈ 40%`. Поправки: Бонферрони (`α / m`), Холм, Бенджамини-Хохберг (контроль FDR). Лучше заранее выбрать одну целевую метрику.

**SRM (sample ratio mismatch).** Сплит 50/50, а получили 50 000 и 48 500 — хи-квадрат даёт p ≈ 2·10⁻⁶. Это баг рандомизации, редиректа или логирования, и результатам доверять нельзя.

```python
from scipy.stats import chisquare
chisquare([50000, 48500]).pvalue    # ≈ 1.8e-06 → SRM
```

**Эффект новизны и change aversion.** Новый интерфейс сначала привлекает внимание или раздражает. Тест должен длиться достаточно долго; эффект смотрят по дням и отдельно для новых пользователей.

**Сетевые эффекты.** В маркетплейсах и соцсетях группы влияют друг на друга; используют кластерную рандомизацию или switchback-тесты.

## Снижение дисперсии: CUPED

CUPED использует ковариату из периода до эксперимента, обычно ту же метрику:

```python
theta = np.cov(x_pre, y)[0, 1] / np.var(x_pre, ddof=1)
y_cuped = y - theta * (x_pre - x_pre.mean())
```

Среднее не смещается, а дисперсия падает в `1 − ρ²` раз: при ρ = 0.7 остаётся 51% — нужна примерно половина выборки. Похожие приёмы — стратификация и пост-стратификация.

## Частые вопросы на собеседовании

- Что такое p-value? → P(результат такой или экстремальнее | H0), а не вероятность H0.
- Что такое мощность и MDE? → Мощность — шанс найти эффект размера MDE; MDE — минимальный обнаруживаемый эффект.
- Почему нельзя останавливать тест при первом p < 0.05? → Peeking завышает ошибку I рода.
- Что делать, если метрик много? → Одна главная метрика, поправки Бонферрони/Холма или FDR.
- Что такое SRM и как проверить? → Несоответствие сплита; хи-квадрат по размерам групп.
- Как ускорить тест? → CUPED, стратификация, более чувствительная метрика, больше трафика.

## Шпаргалка

| Понятие | Значение |
|---|---|
| α | Ошибка I рода, обычно 0.05 |
| Мощность | `1 − β`, обычно 0.8 |
| Выборка | `∝ σ² / MDE²` |
| Доли | z-тест / хи-квадрат |
| Средние | t-тест Уэлча |
| Ratio-метрики | Дельта-метод, бутстрап |
| Бонферрони | `α / m` |
| SRM | `chisquare` по размерам групп |
| CUPED | Дисперсия × `(1 − ρ²)` |
| Peeking | Фиксированный горизонт или sequential |

JavaScript — язык с динамической и слабой типизацией: у переменной нет типа, тип есть у значения, и движок охотно приводит значения друг к другу. Отсюда классические вопросы на собеседовании: почему `typeof null` — это `'object'`, чем `==` отличается от `===` и что такое TDZ. Разберём типы, правила приведения, области видимости и современные операторы `?.` и `??`.

## Примитивы и объекты

В языке семь примитивных типов: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null`. Всё остальное — объекты (массивы, функции, даты). Примитивы неизменяемы и копируются по значению, объекты передаются по ссылке.

```js
console.log(typeof 'a', typeof 1, typeof 1n);   // string number bigint
console.log(typeof undefined, typeof Symbol()); // undefined symbol
console.log(typeof null);                       // object — историческая ошибка
console.log(typeof [], typeof function () {});  // object function
console.log(Array.isArray([]));                 // true
```

| Значение | `typeof` | Как проверять надёжно |
|---|---|---|
| `null` | `'object'` | `x === null` |
| массив | `'object'` | `Array.isArray(x)` |
| функция | `'function'` | `typeof x === 'function'` |
| `NaN` | `'number'` | `Number.isNaN(x)` |

> `typeof` для необъявленной переменной возвращает `'undefined'` без ошибки, но для `let`/`const` в TDZ бросает `ReferenceError`.

## Приведение типов и сравнение

`===` сравнивает без приведения. `==` сначала приводит операнды: `null` и `undefined` равны только друг другу, строка с числом сравнивается как числа, объект превращается в примитив через `valueOf`/`toString`.

```js
console.log('5' - 2, '5' + 2, '5' * '2');   // 3 52 10
console.log([] + {}, [] + []);              // [object Object] (и пустая строка)
console.log(null == undefined, null == 0);  // true false
console.log([] == ![]);                     // true: [] == false → '' == 0 → 0 == 0
console.log(+'', +' 12 ', +'1a');           // 0 12 NaN
console.log(NaN === NaN, Object.is(NaN, NaN)); // false true
```

Оператор `+` при наличии строки склеивает, остальные арифметические операторы всегда приводят к числу. Falsy-значений ровно восемь: `false`, `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`. Всё остальное, включая `'0'`, `[]` и `{}`, истинно.

> На практике используйте `===`. Единственный распространённый случай `==` — проверка `x == null`, которая ловит и `null`, и `undefined`.

## var, let, const и TDZ

`var` имеет функциональную область видимости и при подъёме (hoisting) инициализируется `undefined`. `let` и `const` блочные; они тоже поднимаются, но до строки объявления находятся во временной мёртвой зоне (TDZ).

```js
console.log(a);   // undefined
var a = 1;

{
  var v = 1;
  let b = 2;
}
console.log(typeof v, typeof b); // number undefined

const obj = { n: 1 };
obj.n = 2;        // можно: const запрещает переприсваивание, а не мутацию
console.log(obj.n); // 2
```

| | Область | Hoisting | Повторное объявление | Переприсваивание |
|---|---|---|---|---|
| `var` | функция | да, `undefined` | можно | можно |
| `let` | блок | да, TDZ | нельзя | можно |
| `const` | блок | да, TDZ | нельзя | нельзя |

Function declaration поднимается целиком, поэтому её можно вызвать до объявления. Function expression в `var` — нет: до присваивания там `undefined`.

## Строгий режим

`'use strict'` в начале файла или функции включает строгий режим. ES-модули и тела классов строгие всегда. Основные отличия:

- присваивание необъявленной переменной бросает `ReferenceError` вместо создания глобальной;
- `this` в обычном вызове функции — `undefined`, а не глобальный объект;
- запись в read-only свойство или в замороженный объект бросает `TypeError`;
- запрещены `with` и дублирующиеся имена параметров.

## Опциональная цепочка и ??

`?.` возвращает `undefined`, если левая часть — `null` или `undefined`, и прерывает всю оставшуюся цепочку. `??` подставляет значение по умолчанию только для `null`/`undefined`, в отличие от `||`, который срабатывает на любое falsy.

```js
const user = { settings: { volume: 0 } };
console.log(user.profile?.name.length);     // undefined — .length не вычисляется
console.log(user.settings.volume || 50);    // 50 — ошибка: 0 потерялся
console.log(user.settings.volume ?? 50);    // 0
user.log?.('hi');                           // метода нет — вызова нет
```

## Числа, BigInt и Symbol

Все `number` — 64-битные double (IEEE 754). Отсюда погрешность `0.1 + 0.2` и предел точных целых `Number.MAX_SAFE_INTEGER` (2⁵³ − 1). Для больших целых есть `BigInt` с суффиксом `n`; смешивать его с `number` в арифметике нельзя.

```js
console.log(0.1 + 0.2);                      // 0.30000000000000004
console.log(Math.abs(0.1 + 0.2 - 0.3) < Number.EPSILON); // true
console.log(2 ** 53 === 2 ** 53 + 1);        // true
console.log(2n ** 64n);                      // 18446744073709551616n
console.log(Symbol('id') === Symbol('id'));  // false
console.log(Symbol.for('id') === Symbol.for('id')); // true
```

`Symbol` — уникальный идентификатор, обычно используется как ключ свойства, не конфликтующий с другими. Символьные ключи не видны в `Object.keys` и `JSON.stringify`. Встроенные символы (`Symbol.iterator`, `Symbol.toPrimitive`) задают протоколы языка.

## Частые вопросы на собеседовании

- Почему `typeof null === 'object'`? → ошибка первой реализации, оставленная ради обратной совместимости.
- Чем `==` отличается от `===`? → `==` приводит типы перед сравнением, `===` — нет.
- Что такое TDZ? → участок от начала блока до объявления `let`/`const`, где обращение к переменной бросает `ReferenceError`.
- Чем `??` отличается от `||`? → `??` реагирует только на `null`/`undefined`, `||` — на любое falsy, включая 0 и `''`.
- Как проверить на `NaN`? → `Number.isNaN(x)`; глобальный `isNaN` сначала приводит к числу и считает `'abc'` за `NaN`.
- Как точно считать деньги? → в целых минимальных единицах (копейках) или через `BigInt`, а не дробными `number`.

## Шпаргалка

- 7 примитивов + объекты; `typeof null` — `'object'`, функции — `'function'`.
- Всегда `===`; `x == null` — допустимое исключение.
- `+` со строкой склеивает, `-`, `*`, `/` приводят к числу.
- 8 falsy: `false`, `0`, `-0`, `0n`, `''`, `null`, `undefined`, `NaN`.
- `var` — функция и `undefined`; `let`/`const` — блок и TDZ.
- `const` не делает объект неизменяемым.
- `?.` обрывает цепочку, `??` — только `null`/`undefined`.
- Double: `0.1 + 0.2 !== 0.3`, большие целые — `BigInt`.
